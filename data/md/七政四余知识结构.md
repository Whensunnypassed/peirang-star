**四余的定义**（《稗史汇编·四余星》）：「天尾为计，天首为罗，月之行迟速有常度，迟之处即孛也。气生于闰，二十八年，十闰而气行一周天，无光象，故与罗、计同谓之四余。」
> 由此：罗=天首（白道升交点）、计=天尾（降交点，恒与罗相对）、孛=月行最迟处（月球远地点）、气=闰气（28 年一周天），**与月球近地点无关**——网上部分词条把紫气说成近地点，是把西方 Lilith/Adam 附会上去的。

## 七、顺、逆、留、伏：状态判定

古法（《七政四余择日》第 262–263 页逐字）：

> 「五星三方见太阳则留，留则不行也。五星与太阳同行则伏，伏则不见也。五星对照见太阳则逆，逆则退行也。经云：伏逆无光，而顺行有气。诗云：五星遇日须当伏，三合逢阳便是逆。要识对宫为逆度，不逢阳处顺行周。」

页面的机械判定（水金火木土）：

- **留**：行度绝对值 < 0.0055 °/日
- **顺 / 逆**：行度正 / 负（罗计恒逆，孛气恒顺）
- **伏**：距日 ≤ 10°（在日光下，古籍称「焦伤损力」）；**见**：距日 > 10°，其中距日 90°–170° 为「夕见/晨见」，≥170° 为冲日
- 另有「木炁掩光」「土计夹月」等格局用拱夹/近度条件判定

> 古书又说：「離太陽愈遠，其力愈強」「木火土先太陽東出召力，金水後太陽西入有力」「日月在角內，有初、有中、有背」——这些是程度描述，页面用「距日」数值如实给出，不断言强弱。

## 附：曜状态判定层（2026-10 增补）

规则库命中之后，页面再把命中的条目合成为一个**总体状态**，即点开一曜时顶部那句「太阳状态：好（+1）」。

### 合成方法

每条命中的规则先按断语分档，再按规则类别加权：

| 断语字 | 分 | 断语字 | 分 |
|---|---|---|---|
| 大吉 | +2 | 最凶 | −2 |
| 庙 / 旺 / 受生 / 朝斗 | +2 | 凶 / 怒 / 泄气 / 脱气 | −1 |
| 乐 / 得地 / 朝天 / 独行 / 为生 / 利 / 有生成 / 吉 | +1 | 为奴 / 衰 / 顽 / 受制 / 三丘煞 / 刻剥 / 掩光 / 孤阳 / 轻 / 陷 / 落 | −1 |
| 平平 / 相半 | 0 | | |

权重：**曜×地支宫**（第 1 类）2 分、**成格**（第 3 类）3 分、**曜对曜与日用相对**（第 2、5 类）1 分。

合计 ≥ +1 判「好」，≤ −1 判「不好」，0 判「平平」。

### 新增第 5 类：日、月的相对喜忌

《星命溯源·論七政躔次喜忌》里，**太阳、太阴的喜忌是按「十二宫位」（命/财帛/兄弟/田宅/男女/奴仆/夫妻/疾厄/迁移/官禄/福德/相貌）写的**，须先定命宫才能判——本页不取出生地与时刻，故这一类不参与命中。

但同章还有一批**不依赖命宫、可直接判定**的句子，已补为 13 条规则（第 5 类）：

**太阳**
- 金水引从拱夹（金或水与日同宫/三合）→ 吉（原文：「太陽加臨，金水拱夾，得用日生，則父大吉」）
- 反之为孤阳无辅 → 凶（「太陽無輔，名曰孤陽，男子不得祖業」）
- 木、紫气与日同宫或相距 ≤12° → 木炁掩光，凶（「忌木炁掩光」）
- 罗睺与日同宫或对照 → 罗主刻剥，凶
- 火与日同宫或相距 ≤15° → 犯阳，凶（「火入垣則可，犯陽則不可」）
- 夜生 → 力轻（「夜生人則輕」）；日生 → 吉（「得用日生，則父大吉」）

**太阴**
- 土、计与月同宫或对照 → 最凶（「忌見土計最凶」）
- 火、罗与月同宫或对照 → 稍凶（「火羅稍凶」）
- 金、木、水与月同宫或三合 → 吉（「金木水相隨則吉」）
- 夜生 → 吉（「夜生人最佳」）
- 月距日 80°–100° 或 260°–280°（上下弦）→ 作煞，凶（「如上下弦是煞，則作煞論」）
- 月距日 170°–190°（望，中气）→ 有力，吉（「日月皆論中氣；月上中旬生者有力」）

引擎为此新增了 `any`（任一子条件成立）条件类型；`and`、`not`、`near`、`flank`、`moon_phase`、`night` 等类型此前已有。

### 3D 表达

- **状态环**：每颗星体外围一圈细环，按状态着色——绿=好、红=不好、蓝=平平；默认开启，可用「状态」开关关闭。

2. **格局库**（`moira_t.txt` 第 1973–2338 行，吉格 `+` 134 条、凶格 `-` 104 条、别名 `=` 60 条）：写法是「前缀 + 条件式，`:` 后跟一个 `[a.b.c]` 权重三元组，行尾 `#` 注释」，别名用 `=`。实例：

```
+&{日, 月, 金, 木, 水, 火, 土}垣:[2.0.1] @{}[1]={}          # 入垣
+&{日, 月, 金, 木, 水, 火, 土}殿:[2.0.1] %{}[1]={}          # 升殿
+&{金, 木, 水, 火, 土}生:[2.0.1] @{}[1]=${生{}}
+&日{月, 金, 木, 水, 火, 土, 計, 羅, 炁, 孛}會:[2.2.0] @日=@{}   # 日與某曜同宮
+日月並明:[2.3.0] ?{日月會} & ?晝                              # 晝生合格
=日居日位: {日垣}
```

算子：`@{}` 取该曜所在宫、`@{}[1]` 取该宫的五行属性、`%{}` 取该曜所躔宿、`%{}[1]` 取宿的五行属性、`${生{}}`／`${剋{}}` 取生我／克我之曜、`?{格局名}` 引用已定义格局、`&`／`|`／`!` 逻辑、行内 `?晝`／`?夜` 昼夜。`@{日}=@{}` 一类「同宫」写法天生不依赖命宫，可直接接；需要 `@命`／`@身` 的那部分须先有命宫。

附带的常量表也一并可借：`enemies`（日:月, 月:日, 金:火, 木:金, 水:土, 火:水, 土:木, 炁:金, 孛:土, 羅:水, 計:木）、`helpers`（金:土, 木:水, 水:金, 火:木, 土:火）、`lunar_face_1/2_range`（晦朔 26,5；弦望 11,20）、`boundary_range=1.0`（宫歧／宿歧的容差）、`zodiac_boundary=宮歧`、`stellar_boundary=宿歧`。

## 附三：阵营（阴／阳气息、水／火、昼夜生）的依据与限度（2026-10 增补）

页面「营地」小注与 3D 线条编码（径向短线朝外＝阳曜、朝内＝阴曜；线端单横＝水营、双横＝火营）来自本节，故把依据与限度一并记下。

**1. 阴阳气息——有明文，可直接落地。**
《七政四余古赋注（上册）》：「**日木土气计水为阳星，月火金罗孛为阴曜**」。即阳曜六（日、木、土、炁、计、水），阴曜五（月、火、金、罗、孛）。此为六对五二分，与星曜自身阴阳属性一致。

**2. 昼夜生人——三处互证，且与阴阳二分同构。**
- 《古赋注（上册）》：「昼生从日，从阳。夜生从月，从阴。」
- 《古赋注（中册）》：「分昼夜昼生者。喜太阳木土。计水孛于阳宫阳度。夜生者。爱太阴火金罗于阴宫阴度。如合此者。则福禄崇高……倘或昼曜反于夜。夜星背于昼。以为孤克。」
- 《古赋注（下册）》：「**日生专用日木土，夜生却以金月火**。……日生，论日木土。夜生，论火金月。此理甚明。」
即昼生＝日木土气计水、夜生＝月火金罗孛，与阴阳二分完全同构。异文一处：竖排本《七政四余（全）》作「昼生日木土水计孛、夜生月火金罗」，计与孛互换——本页从文字版《古赋注》。
页面口径：真太阳时 6–18 时为昼生，其余为夜生（与页面既有 `isNightNow()` 判定一致，不新增算法）。

**3. 「水火」——古籍里没有两阵营之分，页面的水火营是图式取象。**
全库检索 `data-md/*.md`，古书中的「水火」都指**水星与火星两颗曜本身**或**二者的一对关系**，从未把十一曜划成水营／火营：
- 「水火既济：水火同宮而水居水度，火居火度，各居本度，谓之水火既济。如在亥宮，有壁水室火，巳宮有翼火轸水，申宮觜火参水也，寅宮则尾火箕水，皆谓之既济。」（中册）
- 「且如水火二星同行，**水能克火，则水为煞星**。如水星在前行，则不能克火。如火星在前，水在后，其煞逼身最为利害。」（中册）
- 「风雷鼓舞……**水火二星各守本宫**，万物得其鼓舞而化育生焉。」（上册）

因此页面的水火营是**取四余五行属**（出自《十干变曜原理》：气→木、罗→火、计→土、孛→水）再按五行归水火所得的图式：**火营＝日·火·罗，水营＝月·水·孛**，金木土与不入水火者记「玄」。这不是古法分类，页面说明段与代码注释均已标注。**要换口径只改一张映射表**（`solar-system.html` 里 `CAMP_SHUIHUO` 一带），绘制逻辑不用动；另两种可选口径：只取水星／火星两曜（贴合古书字面），或按二十八宿宿性（箕水／尾火……）。

**存疑／待办**：「阴阳气息」是否还须按宫位分阴阳（阳宫阴宫）再判一层，古书有「计水孛于阳宫阳度」「爱太阴火金罗于阴宫阴度」之说，即昼夜喜忌还要看**曜落阳宫阳度还是阴宫阴度**；本页目前只按曜性二分，未叠宫度阴阳。
